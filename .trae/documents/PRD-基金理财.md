# 产品需求文档：基金理财网页

## 1. 产品概述

一个专业级基金理财信息展示与模拟交易网页，参考天天基金网业务逻辑，融合原创设计美学。提供基金行情查看、排行榜、基金详情及模拟交易功能，帮助用户了解基金投资流程。

- 主色调：#D4000E（天天基金红）
- 背景色：#F5F7FA
- 文本色：#333（主）、#666（次）
- 目标用户：基金投资者、理财学习者

## 2. 核心功能

### 2.1 功能模块

1. **头部导航栏**
   - Logo与品牌标识
   - 搜索框（基金代码/名称搜索）
   - 热门标签快捷链接
   - 用户登录/注册入口
   - 移动端汉堡菜单

2. **市场行情模块**
   - 主要指数实时展示（上证、深证、创业板、科创50）
   - 指数涨跌动画效果
   - 移动端横向滚动

3. **基金排行榜**
   - 表格展示：排名、基金名称、代码、涨跌幅、近一年收益
   - PC端完整表格，移动端卡片式列表
   - 点击查看详情

4. **热门基金轮播**
   - 自动轮播热门基金推荐
   - 手动切换指示器

5. **模拟交易区域**
   - 基金买入/卖出表单
   - 金额输入验证
   - 模态框确认交易
   - 交易结果反馈
   - 明确标注"模拟交易"提示

6. **底部信息栏**
   - 分栏链接导航
   - 风险提示
   - 版权信息

## 3. 响应式设计

- PC端（>1200px）：完整表格、多列布局
- 平板端（768px-1200px）：自适应列宽、汉堡菜单
- 移动端（<480px）：卡片列表、单列布局、折叠导航

## 4. 技术规范

- HTML5语义化标签
- CSS变量管理颜色体系
- 原生JavaScript ES6+
- 无外部UI框架依赖
- 键盘导航与无障碍支持
