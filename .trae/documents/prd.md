# 个人作品集网站 PRD

## 项目概述

### 项目名称
LLL 个人作品集

### 项目简介
一个年轻、充满活力的个人作品集网站，展示即将进入大学的新生 LLL 的个人信息、技能和作品。网站需要体现年轻人的创造力和个性。

### 目标用户
- 招聘方/HR
- 大学招生官
- 潜在合作伙伴
- 朋友和家人

### 核心目标
1. 展示个人信息和联系方式
2. 展示技能和技术栈
3. 展示作品项目
4. 提供联系方式

## 功能需求

### 1. 首页/Hero区域
- 个人介绍：昵称 LLL、年龄18岁、准大学生身份
- 动态背景效果，体现年轻活力
- 社交链接（QQ邮箱）

### 2. 关于我
- 个人简介
- 兴趣爱好
- 正在学习的方向

### 3. 技能展示
- 技术栈可视化展示
- 技能熟练度

### 4. 作品展示
- 项目卡片展示
- 项目详情（名称、描述、技术栈、链接）
- 支持分类筛选

### 5. 联系方式
- QQ邮箱：1175527050@qq.com
- 其他社交链接

### 6. 导航系统
- 清晰的页面导航
- 平滑滚动

## 设计方向

### 美学风格
- **主题**：未来科技感 + 年轻活力
- **色彩**：深色背景 + 渐变霓虹色调（青色、紫色、粉色）
- **字体**：现代几何字体，体现科技感
- **动效**：流畅的过渡动画、粒子效果、视差滚动

### 视觉元素
- 动态渐变背景
- 玻璃态卡片
- 发光效果和阴影
- 个性化装饰元素
