# 产品需求文档：墨韵 · 数字诗意画廊

## 1. 产品概述

一个融合东方水墨美学与现代数字艺术的沉浸式画廊体验。以"墨韵"为主题，通过流动的墨迹动画、留白美学和诗意的视觉语言，创造一个令人沉思且难忘的数字艺术空间。

目标用户：艺术爱好者、设计师、以及追求独特美学体验的访客。

## 2. 核心功能

### 2.1 功能模块

1. **首页（画廊入口）**
   - 全屏墨迹流动动画背景
   - 呼吸式标题动画
   - 滚动触发的墨迹散开效果
   - 艺术作品展示网格

2. **作品详情（模态展示）**
   - 墨迹边框装饰
   - 淡入式内容展示
   - 诗词文案展示区
   - 相关作品推荐

3. **关于页面**
   - 艺术家介绍
   - 创作理念阐述
   - 联系方式

## 3. 核心流程

用户进入首页 → 被墨迹动画吸引 → 滚动探索作品 → 点击作品查看详情 → 浏览作品信息与诗词 → 返回继续探索或访问关于页面

```
graph LR
    A[进入首页] --> B[欣赏墨流动画]
    B --> C[滚动探索画廊]
    C --> D[点击作品卡片]
    D --> E[查看作品详情模态]
    E --> F[阅读诗词文案]
    F --> C
    F --> G[访问关于页面]
```

## 4. 用户界面设计

### 4.1 设计风格

**主题：东方极简主义 + 数字诗意**

- 主色调：墨黑 `#1a1a1a`、宣纸白 `#f5f0e8`、朱砂红 `#c73e3a`
- 辅助色：青墨 `#2d4a5e`、月白 `#e8e4dc`
- 字体：思源宋体（标题）+ 思源黑体（正文）
- 布局：大量留白，非对称网格，内容悬浮于虚空之中
- 图标风格：无图标，以文字和墨迹线条替代
- 动效：缓慢、流动、如呼吸般自然

### 4.2 页面设计概览

| 页面 | 模块名称 | 设计细节 |
|------|----------|----------|
| 首页 | 墨迹背景 | 全屏Canvas墨迹流动，渐变消散效果 |
| 首页 | 呼吸标题 | "墨韵"二字，scale随时间缓慢变化 |
| 首页 | 作品网格 | 非对称瀑布流，hover时墨迹扩散 |
| 详情页 | 模态弹窗 | 毛玻璃背景，墨迹边框动画 |
| 关于页 | 简约布局 | 居中文字，时间线式历程展示 |

### 4.3 响应式设计

- 桌面优先，移动端简化动画，保留核心视觉
- 触控设备上墨迹动画自动降级为静态渐变

### 4.4 视觉特效

- 墨迹使用粒子系统模拟，自然流动
- 滚动时墨迹根据滚动方向散开/聚拢
- 鼠标悬停时产生墨迹涟漪效果
- 页面切换时墨迹淡入淡出过渡
